# Estructura del Proyecto

```text
src/
├── model/
│   └── Usuario.java             // Modelo POJO (Nombre, CC, Correo)
├── hashing/                     // Responsabilidad: Persona 1
│   ├── Bucket.java              // Manejo de capacidad local y profundidad local
│   └── ExtendibleHashing.java   // Directorio, profundidad global y split
├── search/                      // Responsabilidad: Persona 2
│   └── BusquedaSecuencial.java  // Lista de usuarios y recorrido lineal
└── app/                         // Responsabilidad: Persona 2
    ├── Benchmark.java           // Medición con System.nanoTime()
    ├── DataGenerator.java       // Generador masivo de datos de prueba
    └── Main.java                // Menú de consola e integración general
```

---

## Plan de Trabajo por Persona

### Persona 1: Motor de Hashing Dinámico (Core)

* **Modelo de Datos (`model/Usuario.java`)**
  * Definir la clase con los campos: `nombre`, `cedula` (clave única) y `correo`.
  * Implementar constructor, getters/setters y método `toString()` formateado.
* **Estructura de Bucket (`hashing/Bucket.java`)**
  * Definir la capacidad máxima del bloque ($B$).
  * Gestionar el arreglo o lista interna de usuarios.
  * Controlar la `profundidadLocal` del bucket.
* **Directorio de Hashing (`hashing/ExtendibleHashing.java`)**
  * Implementar el arreglo/lista de apuntadores a buckets y la `profundidadGlobal`.
  * Desarrollar la función hash y la extracción de bits usando máscaras:
    $$\text{hash} \ \& \ ((1 \ll \text{profundidadGlobal}) - 1)$$
  * Implementar el algoritmo de inserción con la lógica de redimensionamiento:
    * División de bucket (*split*) cuando se llena.
    * Incremento de profundidad local y reasignación de elementos.
    * Duplicación del directorio cuando la profundidad local supera a la global.
  * Implementar la función de búsqueda $O(1)$ por cédula.

### Persona 2: Búsqueda Secuencial, Benchmarking e Interfaz

* **Búsqueda Secuencial (`search/BusquedaSecuencial.java`)**
  * Mantener una estructura lineal (`ArrayList<Usuario>`).
  * Implementar el recorrido iterativo $O(n)$ para localizar la cédula.
* **Validación de Duplicados**
  * Implementar la verificación previa a la inserción para garantizar la unicidad de las cédulas.
* **Sistema de Benchmarking (`app/Benchmark.java`)**
  * Implementar temporización de alta precisión usando `System.nanoTime()`.
  * Crear la lógica de comparación de tiempos (Hashing vs Secuencial) y conversión a milisegundos.
* **Generador Masivo (`app/DataGenerator.java`)**
  * Módulo para generar $10.000+$ usuarios sintéticos para apreciar las diferencias de rendimiento real.
* **Interfaz de Consola (`app/Main.java`)**
  * Menú interactivo CLI para insertar, buscar manualmente, cargar lote de datos y mostrar los resultados formateados en consola.
